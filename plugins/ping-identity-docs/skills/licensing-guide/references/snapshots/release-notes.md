# Ping Identity Licensing Guide release notes

Subscribe to get automatic updates: [icon: rss-square, set=fa][Ping Identity Licensing Guide release notes RSS feed](licensing-release-notes.xml)

## 2026

### October 2026

#### October 19

##### Agent Authorize licensing information added

New Agent Authorize

Learn more in [Agent Authorize](../multitenant-saas.html#agent-authorize) in PingOne Multi-tenant SaaS and [Agent Authorize](../advanced-identity-software.html#agent-authorize) in Advanced Identity Software.

##### PingOne Advanced Identity Cloud Enterprise Connect licensing information moved to Archive

Improved PingOne Advanced Identity Cloud Enterprise Connect

The Enterprise Connect and Enterprise Connect Passwordless sections have moved from PingOne Advanced Identity Cloud Workforce and B2B Packaging to the Archive section of the licensing guide. Learn more in [Archive](../archive/archive.html).

##### PingOne Advanced Identity Cloud packaging information updated

Improved PingOne Advanced Identity Cloud

Proxy Connect has been added to the PingOne Advanced Identity Cloud Core and Workforce Core packaging tables. Learn more in [PingOne Advanced Identity Cloud](../pingone-advanced-identity-cloud.html).

### September 2026

#### September 3

##### Enterprise Personal Agent Access licensing information added

New PingOne Privilege Enterprise Personal Agent Access

Enterprise Personal Agent Access licensing information is now available as a new section under PingOne Multi-tenant SaaS Packaging. Learn more in [Enterprise Personal Agent Access](../multitenant-saas.html).

##### PingOne Privilege licensing information updated

Improved PingOne Privilege

The PingOne Privilege section under PingOne Multi-tenant SaaS Packaging has been updated to reflect the current feature set and removes the resource-based unit of measure. Learn more in [PingOne Privilege](../multitenant-saas.html).

##### PingFederate Agent IAM Core licensing information added to PingOne Advanced Services

New PingOne Advanced Services PingFederate Agent IAM Core

The PingOne Advanced Services section of the licensing guide now includes licensing information for PingFederate Agent IAM Core, which treats autonomous artificial intelligence (AI) agents as first-class, governed identities in PingOne. Learn more in [PingFederate Agent IAM Core](../pingone-advanced-services.html).
